# Proxi

一个简洁的 Chrome 代理切换扩展。  
*A clean and lightweight Chrome proxy switcher.*

### 核心特性 / Features

- **直接连接** (*Direct connection*)
- **系统代理** (*System proxy*)
- **全局代理** (*Global HTTP / HTTPS / SOCKS4 / SOCKS5 proxy*)

### 安装 / Installation

[![Chrome Web Store](https://developer.chrome.com/static/docs/webstore/branding/image/UV4C4ybeBTsZt43U4xis.png)](https://chromewebstore.google.com/detail/proxi/cdfidgjjopldhbmpkbpejfofoeafgkbm)  
扩展已经发布到 Chrome Web Store。

1. 点击 **Code → Download ZIP** 下载项目 (*Download via Code → Download ZIP*)
2. 解压 ZIP 文件 (*Unzip the archive*)
3. 访问 `chrome://extensions/` (*Navigate to `chrome://extensions/`*)
4. 开启右上角 **开发者模式** (*Enable Developer mode in the top right*)
5. 点击 **加载已解压的扩展程序** (*Click Load unpacked*)
6. 选择解压目录 (*Select the unzipped folder*)
